# 현업 촬영 방식과 연구 비교군 검토

검토일은 2026-11-13이다. 이번 검토는 PCB/SMT 외관 검사 장비와 산업용 카메라 업체의 공개 기술 자료를 대상으로 한 범위가 제한된 조사다. 업체의 제품 설명과 이번 프로젝트에서 직접 확인한 사실을 구분한다. 공장별 요구 수치·실제 도입 성능·공통 합격 기준은 미확인이다.

## 새 사진 6장의 용도

사용자가 예시로 보낸 사진에는 흰 배경, 회전·원근·배율·촬영 범위 변화가 있다. 6번은 전체 배치의 기준 구도 후보로 활용할 수 있다. 1번은 사선 시점, 2~5번은 부분 확대·방향·범위 변화 사례를 포함한다. 같은 관찰 부위를 원본 좌표에서 연결해야 밝기·선명도 차이를 비교할 수 있다.

여섯 장은 자세·배율·범위 변화가 포함된 미분류 개발 예시로 관리한다. 원본은 local-only INPUT_RECEIPT.json 및 supplied/에 해시와 함께 보존했다. 조명·반복·실제 결함 라벨은 unknown이다. 이번 단계의 수행 범위는 파일 보관과 시각 검토, 비교군 설계다. 흰 배경의 예시는 기존 나무 배경의 개발 입력과 별도 세션으로 기록한다.

## 업체 자료에서 확인한 촬영·운영 요소

| 자료 | 확인한 내용 | 프로젝트에서 적용할 설계 |
|---|---|---|
| MIRTEC MV-6 OMNI | 고해상도 카메라, 다단 동축 컬러 조명, 모아레 3D 및 측면 카메라 옵션 | 촬영 위치·FOV·광원·관찰 ROI를 recipe로 기록하고 고정 다중 조명 대조군을 둔다 |
| Basler Triggered Image Acquisition | 외부 전기 신호, 내부 신호 또는 소프트웨어 명령으로 촬영 시점을 지정 | part/cycle ID와 촬영 요청·수신·완료 이벤트를 연결한다 |
| Basler GigE Line Scan Use Cases | 컨베이어 객체 트리거와 이동에 동기화하는 encoder 활용 예시 | 정지 촬영형과 연속 이동형의 시간·형상 변동을 구분한다 |
| Koh Young 검사 공정 최적화 자료 | 품목별 recipe·허용 범위, false call 대응, cycle time과 엔지니어링 작업 | 미검·정상 오탐·재검 부하·전체 처리 시간을 함께 보고한다 |
| Koh Young AOI 기술 자료 | 반사·그림자, false calls/escapes, 장비 상태 점검과 추적성 | 반사량 하나로 결함을 단정하지 않고 기준 부위·결과 이력을 관리한다 |

이 자료들은 촬영 조건을 설계 변수로 다룰 근거다. 상용 3D 사양은 해당 제품의 기능 설명으로 기록한다. 현재 실물은 조립 PCB 외관의 입력·표면 판독 시연으로 연결한다. 납땜 높이·체적·숨은 접합부와 전기적 기능은 별도 계측 범위다.

## 이번 프로젝트의 기준 구성

초기 실물 구성은 정지된 기판을 고정 카메라로 촬영하는 수동 입력 스테이션으로 잡는다. 품목 식별, 위치 맞춤, 정해진 관찰 영역 촬영, 품질 확인, 검사 또는 REVIEW, 재촬영·결과 기록을 연결한다. 실제 PLC·카메라 트리거 신호가 없으면 소프트웨어 이벤트로 구분한다.

카메라 각도·거리·FOV·렌즈 배율·초점·노출 모드·조명 위치·반사·필요 특징의 픽셀 크기를 recipe에 넣는다. 물리적 길이를 확인할 기준이 있으면 pixel/mm와 목표 특징 크기를 계산할 수 있다. 현재 사진의 mm 분해능, lux, 물리 trigger latency는 미측정이다.

## 가장 먼저 둘 비교군

주 비교군은 ‘고정 촬영 recipe에서 원본으로 직접 검사’다. 추가 구매 없는 환경에서 촬영 조건을 정리하는 것만으로 얻는 효과를 먼저 확인한다. 무정책·임의 촬영 입력은 robustness 스트레스 사례로 활용한다.

| 조건 | 촬영·처리 | 비교 질문 |
|---|---|---|
| C0 | 고정 recipe, 원본 1장, 동일 검사기 | 현재 환경의 직접 검사 기준 |
| C1 | 같은 recipe와 입력, 고정 복원 처리 후 동일 검사기 | 복원 자체의 이득·손실과 추가 비용 |
| C2 | 같은 첫 입력, 품질 정책에 따라 정해진 대체 조명으로 최대 1회 재촬영 | 조건부 재촬영의 최종 판독·검사 효과와 촬영 비용 |
| C3 | 두 개의 고정 조명을 항상 촬영, 최대 2장으로 검사 | 다중 조명 촬영 자체의 효과와 C2의 촬영 절감 가능성 |

현재 v0.1 고정 clipping/선명도 규칙은 C2의 기본 정책으로 남긴다. 새 정책은 같은 C2 조건에서 별도 ablation으로 비교한다. 주형 담당자가 정상 참조 사진·관찰 부위·기존 코드의 한계를 검토해 단일 후보를 선택하고 첫 평가 전에 고정한다. 개선안 하나의 효과와 비용을 먼저 비교한다.

C0/C1은 같은 입력 1장을 사용한다. C2/C3는 같은 최초 사진과 같은 사전 지정 두 번째 조명을 사용하며 촬영 예산을 최대 2장으로 맞춘다. C3의 조명별 참조·검사 및 최종 결합 규칙도 평가 전에 고정한다. GT를 보고 두 장 중 좋은 사진을 선택하는 oracle은 별도 post-hoc 분석으로 표시한다.

실물에 적용할 검사기는 우선 정렬 후 golden-reference 차이를 보는 작은 baseline을 검토한다. 실제 검출 성능은 별도 라벨과 모사 이물 사진이 확보된 범위에서 평가한다. 새 그래픽카드의 참조·입력과 기존 MVTec/VisA bank의 domain을 별도 family로 기록한다. 현재 phone 도구의 detector 상태는 not_connected다.

## 결과에서 크게 비교할 것

현장 요구에 맞춘 단일 합격 수치는 정해져 있지 않다. 이번 연구에서는 기존 benchmark의 pooled AU-PRO primary를 유지하고 운영 지표를 별도로 추가한다. 허용 미검 수준이 나중에 주어지면 그 제약에서 정상 오탐·재검 부하·시간을 비교한다.

- NG 미검 비율은 확인된 NG 중 최종 OK가 된 수를 분모와 함께 기록한다. 출하품 중 NG 비율을 보고한다면 최종 출하 수를 분모로 둔 별도 지표로 명시한다.
- 정상 오탐 비율은 확인된 정상 중 최종 NG 비율로 정의한다. 정상의 NG 또는 REVIEW 전환 비율과 전체 REVIEW 부하도 따로 남긴다.
- 입력 품질 정책은 독립적으로 기록한 판독 가능 여부와 대조한다. 판독 가능한 입력의 과도한 거부, 판독 어려운 입력의 허용, 재촬영 후 해결·미해결 수를 포함한다.
- 모든 최초 cycle을 분모로 유지한다. PASS 사진만의 결과와 전체 운영 결과를 함께 표시하고 미해결·오류를 누락하지 않는다.
- 촬영 횟수, 소프트웨어 처리 시간과 실제 관측된 작업 시간을 구분한다. 실제 acquisition과 재촬영·통신·검사·기록을 포함한 cycle time이 있으면 median/p95를 보고한다. Simulator 시간으로 장비 처리량을 계산하지 않는다.
- 같은 부품의 반복성과 세션 간 재현성을 구분한다. 독립 부품 수와 같은 부품의 반복 사진 수를 함께 명시한다.

실제 정상·결함 라벨이 없으면 NG 미검과 정상 오탐은 NA다. 입력 품질 수치와 사람의 표면 판독 기록은 확보한 범위에서 보고할 수 있다. 상용 장비에서 사용하는 component/joint 단위와 이번 board/cycle 단위의 분모도 구분한다.

## 현재 코드에서 검토할 지점

첫 어댑터에서는 검은 재질과 clipped-low 알림이 함께 관측됐다. 첫 그래픽카드의 개발 ROI는 high-clipping1.05191%로 기존1%기준을 조금 넘었다. 두 경우 모두 일반 clipping 규칙과 실제 관찰 부위의 판독 가능성을 대조할 필요가 있다. 정책 선정은 정상 development 참조에서 근거를 기록하고 별도 평가 세션에 고정 적용한다.

주형 담당자는 ‘관찰 ROI가 실제로 보이는가, 원본 화소의 특징이 유지되는가, 정상 참조 대비 새 반사 영역이 생겼는가’를 포함한 단일 개선안을 검토한다. Raw/unwarped 품질 계산, 정렬 실패·ROI 범위 손실·재질의 본래 밝은 영역을 분리한다. 기존 v0.1 결과는 그대로 보존하고 개선안은 새 버전과 별도 세션으로 평가한다.

## 포스터와 시연의 출력

기존 SR/PatchCore 정량 결과, 촬영 recipe와 품질·검사 흐름, 같은 cycle의 원본/대체 조명/판독 영역/알림/재촬영 이력을 묶는다. 클릭해서 전체 이력을 보는 기존 HTML과 CSV를 재사용한다. 실제 미검 감소가 확인될 때 그 범위와 표본 수를 붙인다.

보유 UNO와 USB 케이블을 사용할 수 있으면 기존 InspectionStation 출력 상태를 내장 LED로 표시하는 추가 시연을 설계할 수 있다. 연결 가능 여부와 실제 구동은 미확인이다. 실제 구동 전에는 fake-controller로 상태 계약을 확인한다. 결과표의 광학 검사 대상과 상태 표시용 MCU 역할은 분리한다.
