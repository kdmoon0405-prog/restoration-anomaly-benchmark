# 주형에게 전달할 추가 촬영 요청

2026-11-17 촬영 전 제안. 기존32장 평가 계획을 보강한 기본32장과 작은 모사 이물의 열화 비교18장, 총50장이다. 사진마다 실제 파일명과 촬영 상태를 capture_plan_50.csv에 적는다. 기존 사진으로 가능한 비교 작업은 별도로 계속한다.

## 왜 더 찍는가

현재24장은 방법을 정할 때 사용한 development 사진이다. 기존 새32장 계획은 정상 기판의 저조도·흐림을 다룬다. 이물이 있는 채로 어둡거나 흐릴 때도 이물이 남는지 확인하려면 같은 이물을 유지한 사진 묶음이 필요하다.

## 촬영 준비

- 같은 기판의 같은 면을 사용한다. 카메라를 책·거치대 등에 고정하고 가능한 한 기판과 평행하게 둔다. 네 모서리가 보이면서 기판이 화면 대부분을 차지하게 한다.
- 기판과 폰의 위치, 조명 L0와 L1의 위치를 테이프로 표시한다. L0는 기준 조명, L1은 옆에서 비추는 대체 조명이다. 첫 촬영에 표시 위치를 설명한 메모나 배치 사진을 남기면 재현에 도움이 된다.
- 일반 사진 모드·같은1×렌즈·원래 해상도를 유지한다. 디지털 줌, 미용/필터, 촬영 후 보정은 끈다. 플래시와HDR, AE/AF잠금의 실제 상태를 기록한다. JPEG 원본을 파일로 전달한다.
- 선명한 사진은 초점을 맞춰 촬영한다. 저조도에서는 카메라가 자동으로 다시 밝게 만들었는지 확인하고 노출 잠금 여부를 기록한다.
- 흐림은 실제 촬영에서 초점을 벗어나게 만든다. 초점 조절이 가능한 촬영 앱인지 먼저 확인한다. 기판·카메라 자세는 유지하고, 대체 사진에서는 계획에 따라 초점을 되돌린다. 실제 흐림을 만들지 못한 칸은 미촬영으로 남기고 주형에게 알린다.
- 한 cycle은 최초 입력1장과 대체 입력1장의 묶음이다. 두 장 사이에 기판과 이물을 움직이지 않는다. 촬영 실패본도 보관하고 다시 찍은 사진은 attempt를 구분한다.

## A. 새 기본 평가32장

| 묶음 | 촬영 방법 | 사진 수 |
|---|---|---|
| 참조 | 이물 없이 선명하게 L0와L1 각각1장 | 2 |
| 정상 보정 | 참조와 따로 셔터를 눌러 이물 없이 L0와L1 각각1장 | 2 |
| 정상 평가 | 이물 없이 최초L0/대체L1의 묶음을4회 | 8 |
| 기존 큰 모사 이물 | 기존 분홍 조각을P1/P2/P3에 놓고 위치마다2묶음. 최초L0/대체L1 | 12 |
| 정상 저조도 | 이물 없이 어두운 최초L0/선명한 대체L1을2묶음 | 4 |
| 정상 흐림 | 첫묶음은 흐린L0/선명한L1, 둘째는 흐린L0/흐린L1 | 4 |
| 합계 | 참조·보정4장과 평가14묶음28장 | 32 |

P1은기판가운데, P2는왼쪽소자밀집영역의빈표면, P3는오른쪽메모리칩사이의빈표면으로 정한다. 기존32장v1에서 둘째 흐림묶음의L1도흐리게 바꾼 v2제안이다. 실제촬영 전에 주형이 이 버전을 확인·고정한다. 참조·보정 사진을 평가·대체 사진에 다시 넣지 않는다.

## B. 작은 모사 이물을 둔 열화 비교18장

작은 모사 이물1종을 정해 크기를 유지한다. 예를 들면 얇은 실 한 조각이나 작은 종이 조각을 쓸 수 있다. 실제 원본에서 위치를 읽을 수 있는 크기인지 선명한 기준 사진으로 확인하고 종류와 크기를 메모한다. 정확한 길이를 재지 못했으면mm수치를 추정하지 않는다.

서로 다른표면위치3곳을M1/M2/M3로 정한다. 위치별로 아래6장을 촬영한다. 총18장이다.

| 한 위치에서 찍을 묶음 | 최초 입력 | 대체 입력 | 사진 수 |
|---|---|---|---|
| 선명 기준 | 이물이 있는 선명한L0 | 이물이 있는 선명한L1 | 2 |
| 저조도 | 같은 이물이 있는 어두운L0 | 이물을 유지하고 선명한L1 | 2 |
| 흐림 | 같은 이물이 있는 흐린L0 | 이물을 유지하고 초점을 맞춘L1 | 2 |

각위치의6장 동안 기판·이물·카메라 위치를 유지한다. 위치를 바꾸면 새case다. 저조도와흐림을만드는방식도기록한다. 대체사진은매번새로찍는다. 보조18장은기본32장과별도묶음으로분석하고,같은기판·이물반복임을표시한다.

이18장의 선명촬영본은 비교참조다. 조명·노출·미세자세가다르면정확한픽셀GT로가정할수없다. 모사표면이물로확인한범위와실제제조미세결함의검증범위를보고서에구분해서적는다.

## 기록과 전달

- capture_plan_50.csv는실제촬영전계획표다. file열은실제파일명을입력하고,조명·노출/초점상태·attempt·모사이물종류/위치·촬영시간을적는다.
- cycle마다 조명·초점을설정하기시작한때부터대체사진의셔터가끝난때까지 시간을재서첫사진행의capture_seconds에적는다. 재지못하면빈칸으로남긴다.
- 사람이 알고리즘 결과를 보기 전에 사진별로 well_visible/hard_to_read/uncertain을 판독하고,가능하면작은이물도위치를읽을수있는지별도메모한다. 제공한human_legibility_blank.csv를사용한다.
- 원본사진폴더,기록표,사람판독표를함께비공개로전달한다. 캡처화면이나메신저자동축소본 대신원본파일을첨부한다.
- 실제찍은사진수·누락칸·촬영방식변경을함께적는다. 표의계획행을실제촬영완료로바꾸지않는다.

이촬영안은추가구매없이같은폰·기판·조명으로진행하는범위다. 주형은먼저보유사진과비교해중복촬영필요성을확인하고,촬영이진행되는동안기존RGB비교·bank실험·보고서를계속한다.
