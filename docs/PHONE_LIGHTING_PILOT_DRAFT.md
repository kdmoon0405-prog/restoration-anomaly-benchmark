## 최종 산출물

조명 조건을 바꿔 촬영한 같은 부품을 정렬하고, 입력 품질·결함 반응·판정 변화를 함께 보여주는 로컬 검사 도구를 만든다. 기존 SR 연구의 저장 결과를 설명하는 표와 실물 촬영을 연결한다. 목표 화면은 원본 사진, 과노출/저노출 위치, 정렬 상태, 검사 ROI, 탐지 map, 촬영 recipe, 판정·재촬영 이력이다. CSV와 정적 그림, 재현 가능한 시연 영상을 함께 남긴다.

첫 구현은 폴더 입력을 사용한다. 기존 results viewer와 fake-controller 계약을 재사용할 수 있는지 확인한다. 실시간 카메라 연결은 촬영 방식이 정해진 뒤 별도 범위로 둔다.

## 첫 촬영 요청

- 스마트폰과 기판 위치를 책상 위에서 고정한다. 책이나 기존 거치물을 사용할 수 있다.
- 책상 조명을 왼쪽·정면·오른쪽의 세 위치로 옮겨 각 조건에서 세 장씩 촬영한다. 첫 입력은 같은 기판의 9장이다. 실제 사용 가능한 조명 위치를 사진과 기록으로 남긴다.
- 촬영 앱이 지원하면 초점·노출을 고정하고 필터와 자동 HDR 상태를 기록한다. 기능이 없으면 미확인으로 기록하고 EXIF의 ISO·노출시간 등 확보 가능한 값을 보존한다.
- 스마트폰 기울기 변화는 두 번째 실험 축으로 분리한다. 플래시는 기본 조명 세 조건 이후 별도 recipe로 기록한다. 물리적 조도계를 사용하지 않으므로 밝기를 lux로 표기하지 않는다.
- 원본 해상도 사진과 EXIF를 로컬 보존한다. 공개 전에는 위치정보·개인 경로·배경의 개인 정보를 별도로 검토한다.
- 결함이 확인된 실물이 있으면 해당 위치를 별도 주석으로 기록한다. 모사 결함은 실제 제조 결함과 구분한다. 기판 한 개의 반복 촬영 결과는 동일 물체의 조건 변화·반복성 범위로 해석한다.

## 알고리즘 범위

1. 입력 manifest와 정렬. part_id, capture_session, recipe_id, repeat_id, camera/exposure metadata와 파일 SHA를 저장한다. 같은 실물의 사진은 동일 part_id로 묶는다. 고정 ROI와 기준 영상은 development 촬영에서 정한다. 정렬 잔차와 실패 상태를 보고한다.
2. 입력 품질 계측. ROI 내 포화/암부 비율, 밝기 분포, gradient 기반 선명도와 정렬 오차를 계산한다. 선명도와 local contrast는 질감·노이즈에도 영향을 받으므로 결함 검출 성능과 별도로 보고한다. 포화 판정의 디지털 값 기준과 색/밝기 변환식을 구현 전에 기록한다.
3. 비교 후보. 원본 고정 조명, 단일 고정 조명 보정 알고리즘, 품질 기반 촬영 recipe/재촬영의 세 후보를 제안한다. 보정은 shading 보정 등 하나로 좁히고 development에서 고정한다. 조명 보정의 선택 이유와 비용을 기록한다. 기존 Bicubic/SwinIR/실사형 복원 모델 결과는 protocol family를 구분해 연결한다.
4. 품질 기반 정책. Development 정상 영상에서 기준을 정하고 test GT를 전달하지 않는다. 낮은 품질·정렬 실패·누락 입력은 REVIEW/재촬영 상태로 보낸다. 재촬영 횟수, 미해결 비율과 전체 부품 수를 유지해 집계한다. 미해결 사례를 평가에서 제외하지 않는다.
5. 탐지 연결. 실물 사진용 정상 reference/bank와 calibration은 별도로 구성한다. VisA bank의 실물 사진 적용은 domain-transfer 대조로 표시한다. 정상 영상만 있으면 품질·점수 반복성을 먼저 보고하고, 확인된 정상/결함 입력과 독립 평가 대상이 확보됐을 때 오검·미검을 평가한다.

안정성만 좋아지면서 결함 반응도 낮아질 수 있다. 점수 분산·판정 뒤집힘과 오검/미검, REVIEW 및 재촬영률을 함께 보고한다. 같은 물체의 조건별 사진을 독립 부품 수로 세지 않는다. 물리적 반복 촬영의 PSNR/SSIM은 정렬·노출 차이도 포함하므로 SR ground truth로 간주하지 않는다.

## 일정 초안

- 11월 12~16일에 첫 9장 확인, 촬영 recipe와 파일 계약, CPU 품질 리포트를 준비한다.
- 11월 17~23일에 실물/촬영 세션 단위 development·평가 분할과 알고리즘을 고정하고 보유 입력으로 비교한다.
- 11월 24~30일에 고정된 평가, 재촬영 정책의 비용·오검·미검, 기존 연구 결과 연결, 화면과 시연 영상을 완성한다.
- 12월 1~3일에는 보고서·발표 자료·재현 패키지를 마무리한다. 정확한 제출일과 확보 가능한 실물 수량은 추후 확인한다.

사진이 적으면 동일 물체 조건 실험으로 최종 범위를 명시한다. Photometric stereo는 여러 조명 영상에서 표면 법선을 추정하는 확장 후보다. 스마트폰의 자동 처리와 조명 보정 수준을 먼저 확인해야 하므로 3D 치수·높이 계측은 추가 근거가 필요한 별도 목표로 둔다.
