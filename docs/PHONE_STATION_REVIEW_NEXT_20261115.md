# 스마트폰 촬영 스테이션 검토 후속 작업

11월 15일 반환 `handoff/juhyung@7b2c894`의 CPU 재집계 결과는 [검토 보고서](../analysis/phone_station_return_20261115/REVIEW.md)에 있다. 실행 source는 `5839caa`다. 사용한 Claude Fable 5.2 모델 식별자는 담당자 실행 기록에서 확인했다.

## 지금 마칠 수 있는 작업

1. 포스터와 공개 PROGRESS에 전체 16건의 C3 NA 9건을 표시한다. C2와 C3의 사진 사용 비교에는 같은 7건의 10회·14회를 사용한다. 참조·보정 재사용 2건을 제외한 사후 진단 5건은 6회·10회이며, 남은 공통 대체 사진 재사용을 명시한다. 실제 촬영 시간과 독립 평가 성능은 미측정으로 둔다.
2. C1 Bicubic과 SwinIR의 최종 판정이 16건 모두 같았다는 결과와 `phone_x4_roundtrip` 정의를 반영한다. 현재 UI·포스터에서 사진 수는 오프라인 논리적 사용 횟수로 표시하고 소프트웨어 시간과 실제 촬영 시간을 구분한다. 기존 consumer의 cohort CSV와 재사용 ledger를 재사용한다.
3. 공개 가능한 코드·포스터 초안·수치·PROGRESS를 run/commit으로 반환한다. 실제 private 결정 노트의 새 부분은 마지막 결정 ID와 함께 비공개 반환한다. 이전 D01~13은 수신 완료다. 이번 개발 설계·수정에 해당하는 원문은 아직 CPU 중앙 노트에 도착하지 않았다.

## 새 평가 입력을 받으면 한 번 실행할 작업

현재 v0.2와 golden-reference를 유지한 작은 새 세션 계획을 먼저 기록한다. 기준 변경이 필요하면 그 변경을 새 입력 비교 전에 고정한다. C0·C3를 우선 비교하고 C2·C1 Bicubic·SwinIR을 같은 사례에 연결한다. 참조와 보정 사진을 평가·대체 사진으로 재사용하지 않고 사례별 대체 사진을 따로 둔다. 두 번째 사진이 없는 사례는 NA로 남긴다.

스마트폰·책상 조명·플래시와 기존 지지물만 사용한다. 카메라·보드·ROI·배율·배경·조명 위치를 기록하고 새 세션 동안 고정한다. AE/AF 잠금과 HDR은 실제 상태를 적는다. 한 사례의 두 조명은 같은 보드·같은 모사 이물 상태를 유지한다. 사람이 검사 정보를 읽을 수 있는지 별도 라벨을 기록하고 촬영 시작부터 판정까지 실제 시간을 잰다. 모사 이물 반복과 실제 제조 결함은 각 출처에 맞게 표기한다.

현재 사진은 정상 부품인지 전기적으로 확인되지 않았다. 한 보드·한 위치 반복에서 공장 미검률·오탐률·takt time을 추정하지 않는다. 선명도 밝기 정규화의 조명 독립성은 추가 근거가 생길 때 검토한다. 포스터 초안과 기존 확정 실험은 이 새 촬영을 기다리지 않고 진행한다.
