# 사진 결과물 중심의 현재 상태와 다음 작업

2026-11-17. 사용자는 실시간 시연의 유무와 별개로 눈으로 비교할 수 있는 사진 결과물을 우선한다. 지혁의 미완료 bank-domain 실행은 주형에게 이관한다. 첨부 가이드는 연구 확장과 하드웨어 제작 제안을 함께 담고 있다. 다음 평가는 받은 코드, 실행 기록, 실제 PDF/PPTX, 사진 그림과 CSV를 기준으로 한다.

## 현재 확인한 범위

| 목표 | 확인한 결과 | 이어서 필요한 결과 |
|---|---|---|
| 열화와 결함 보존 연구 | 기존 SR/PatchCore 비교, 실패 사례 분류, native tiling, 저장 점수 분석이 있다 | 같은 결함 위치의 원본·열화·Bicubic·SwinIR 확대 사진과 대응 검사 지도 |
| 실물 입력 처리 | 폴더 입력, 정렬, 관찰 영역 품질, 기준 사진 차이 검사, 대체 사진, 판정·이력이 구현됐다 | 새로 고정한 촬영 세션과 사람 판독 기록 |
| 사진으로 설명하는 결과 | 모사 이물 위치와 차이 지도, 저조도 입력과 대체 조명 그림을 확인했다 | 작은 부품·배선·결함을 읽을 수 있는 확대 패널 |
| 정상 특징 bank의 도메인 비교 | 실행 코드와 CPU 분석기, CPU HOG 대조 결과가 있다 | 실제 PatchCore 24개 기본 조건과 4개 확장 조건, 동일 query의 bank별 지도 |
| 선택적 복원·드리프트 보정·검색 가속 | 가이드의 추가 설계 제안이다 | 채택한 항목만 별도 구현·측정 |
| UNO·조명 피드백·XY 스캐너 | fake serial 경로와 UNO 초안이 있다 | 실물 연결과 계측은 장비 확보 뒤 진행 |

현재 실물 그림은 그래픽카드 뒷면 1개, 한 세션의 사진이다. 모사 표면 이물 1종·1위치를 3회 반복한 개발 결과를 보여준다. 차이 영역의 면적은 복원 화질이나 결함 검출 정확도와 구분해서 표시한다. 큰 색 이물의 NG 결과를 미세 결함 보존 성능으로 확대해 쓰지 않는다.

현재 운영 16 cycle은 OK 6, NG 4, REVIEW 6이다. 정상 라벨 13 cycle은 OK 6, NG 1, REVIEW 6이고 모사 이물 3 cycle은 NG 3이다. REVIEW의 후속 사람 판독이 남아 있다. 같은 7 cycle에서 C2와 C3의 논리 사진 사용은 10회와 14회다. 재생한 대체 사진의 공유·참조/보정 재사용과 C3 NA 9건을 유지해서 보고한다.

현재 phone C1의 축소·복원 비교에는 인위적인 x4 열화가 들어간다. 실제 저조도나 흐림의 복원 성능과 같은 이름으로 묶지 않는다. Bicubic과 SwinIR의 최종 판정은 현재 16 cycle 모두 같다.

## 코드의 구현 주체

주형 반환에는 phone_* 기능, 실행기, 보고서와 포스터 생성 코드가 있다. RUN_RECORD에는 설계·구현·본문·자체 검토를 Claude Fable 5.2로 진행했고 후반 기록·포장·반환은 사용자 전환에 따른 Opus 5.5로 진행했다고 적혀 있다.

전체 저장소에는 기존 SR/PatchCore 구성, 팀원의 실행 코드, CPU 분석·통합 코드가 함께 있다. 전체 코드를 주형 한 사람의 작업으로 귀속할 근거는 없다. 지혁의 bank-domain 코드를 이어받는 범위와 새로 수정한 범위를 기록한다.

## 다음 반환에서 먼저 볼 그림

1. 기존 데이터의 고정된 결함 위치에서 원본, 열화 입력, Bicubic, SwinIR을 같은 범위·크기로 놓는다. 원본 GT가 있으면 대응 GT와 검사 지도도 넣는다.
2. 기존에 분류한 개선·결함 억제·형상 변화·변화가 작은 사례를 포함한다. 생성된 RGB가 없는 경우 고정된 선정 사례의 RGB만 다시 저장하는 유한 실행을 한다.
3. 같은 query RGB를 유지한 채 clean bank와 SwinIR-restored bank의 검사 지도를 비교한다. bank 변경의 효과와 query 복원의 효과를 나눠 기록한다.
4. 실제 스마트폰 사진은 기준·저조도·대체 조명과 모사 이물을 확대해서 보여준다. 실물 결함 GT가 없으면 위치 표시를 GT로 부르지 않는다.

첫 사진 묶음은 bank 24+4 전체 실행이 끝나기 전에 반환할 수 있다. UNO 실물도 이 사진 묶음의 선행조건이 아니다.

## 확인한 수정 사항

- 실제 A0 PDF 1쪽과 PPTX 1슬라이드를 열었다. 크기는 약 841×1189 mm다. 팀 번호·저자·지도교수·소속의 미확정 표기가 남아 있다.

- 결과 HTML의 v0.2 문구는 저장된 결과를 이용한 렌더링 또는 사본의 문구 수정으로 정정할 수 있다. 문구만 고치기 위한 전체 모델 재실행은 필요하지 않다.
