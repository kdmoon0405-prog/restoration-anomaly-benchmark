## 촬영 규칙 (v1에 더하는 것)

- 작은 이물은 1종으로 정하고 크기를 바꾸지 않는다. 종류는 메모하고, 길이를 재지 못했으면 mm를 쓰지 않는다.
- 위치 M1, M2, M3마다 6장을 찍는 동안 기판·이물·카메라를 움직이지 않는다. 위치를 바꾸면 새 case다.
- 저조도는 방 조명을 끈다. 카메라가 자동으로 밝게 보정했는지(노출 잠금 여부)를 적는다.
- 흐림은 수동 초점으로 만든다. 흐리게 만들지 못한 칸은 비워 두고 "미촬영"으로 적는다.
- 모든 사진은 한 번씩만 쓴다. 참조와 정상 보정 사진은 평가·대체 사진으로 다시 쓰지 않는다(실행기가 거부한다).

## 분석 (고정)

- 방법은 품질 정책 v0.3과 golden-reference v0.1이다. 임계값은 이 세션의 참조·정상 보정 사진으로만 정한다.
- 보고는 묶음별로 따로 한다.
  - 기본: 14 cycle (정상 8, 큰 이물 6)
  - 보조: 9 cycle (작은 이물)
- 두 묶음을 합치지 않는다. 같은 기판·같은 이물의 반복은 독립 결함 수로 세지 않는다.
- C0와 C3를 먼저, 이어서 C2 v0.3 / v0.2 / v0.1, C1 Bicubic / SwinIR 순서로 쓴다.
- 이물 위치 표시는 방법 실행 뒤 case마다 한 번 하고, 위치 일치 확인에만 쓴다. 정밀 픽셀 GT가 아니다.
- 선명한 촬영본은 비교 참조일 뿐이다. 조명·노출·미세 자세가 다르므로 PSNR/SSIM의 정답으로 쓰지 않는다.
