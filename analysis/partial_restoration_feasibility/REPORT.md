전체 복원이 입력보다 좋아졌던 4장 중 4장에서 부분 복원이 그 이득을 줄였다. 이 영상들의 AU-PRO 감소량 합은 0.018015이다.
전체 복원이 입력보다 나빠졌던 4장 중 3장은 부분 복원이 전체 복원보다 높았다.

변화가 큰 두 사례를 결과 확인 후 설명용으로 골랐다. 실험 표본 선택은 바꾸지 않았다.

- `hazelnut/test/crack/001.png`: 전체 0.961348 → 부분 0.981306, Δ +0.019959.
- `hazelnut/test/print/001.png`: 전체 0.912929 → 부분 0.904820, Δ -0.008109.

평균 per-image AU-PRO와 pooled AU-PRO는 서로 다른 집계다. 한쪽 증가를 다른 쪽 증가로 표현하지 않는다.
정상 영상에는 per-image AU-PRO를 부여하지 않았다. -0.01은 기술적 손실 크기이며 허용 기준이 아니다.
새 조건의 정상 보정을 하지 않았으므로 F1 또는 고정 FPR의 안전성을 주장하지 않는다.

보호 영역과 RGB 구성에 GT를 사용하지 않았다. 두 baseline의 기존 저장 map 재현을 확인했다.
임계값·표본·보호 영역을 결과에 맞춰 변경하지 않았다. 추가 실험은 자동으로 수행하지 않는다.

## 이번 결과에 대한 판단

부분 복원은 전체 복원보다 평균 per-image AU-PRO가 `+0.000839` 높았지만 pooled AU-PRO는 `-0.004717` 낮았다. 균일 혼합과 비교해도 평균 per-image 차이는 `+0.000357`인 반면 pooled 차이는 `-0.005284`다. 평균 per-image의 작은 증가로 전체 성능 개선을 주장할 수 없다.

입력 대비 최악의 per-image 손실은 전체 복원 `-0.021142`, 부분 복원 `-0.007157`로 줄었다. 입력 대비 `ΔAU-PRO < -0.01`인 영상도 1장에서 0장이 됐다. 그러나 strict negative는 4장에서 6장으로 늘었고, 전체 복원이 입력보다 좋아졌던 4장 모두에서 부분 복원은 그 이득을 줄였다. 균일 혼합의 같은 네 영상에서 이득 감소량 합은 `0.001303`, 부분 복원은 `0.018015`였다. 일부 큰 손실을 줄이는 대가를 함께 봐야 한다.

`crack/001`의 손실 완화는 확인됐지만 현재 보호 규칙을 전체 복원이나 균일 혼합보다 우월한 주력 방법으로 채택할 근거는 부족하다. 이 고정 규칙의 feasibility 시험을 여기서 마치고, 알고리즘과 결과를 별도 기록으로 보존한다. 모든 선택적 복원 방법이 실패한다거나 의심 영역 보존이 일반적으로 무효라고 결론내리지는 않는다.

검증: 저장된 두 baseline의 10장 map을 다시 추론한 결과, 기존 normalized map과의 최대 절대 차이는 20개 비교 모두 `0.0`이었다. 실행 후 원래 bank·checkpoint·결과·split·표본·평가 코드 checksum을 다시 확인했다. 저장된 RGB가 보호 마스크 구성식과 일치하고, prediction NPZ에서 다시 계산한 32개 결함 per-image AU-PRO 및 네 조건의 summary/comparisons가 CSV/JSON과 일치했다.

비교 그림의 행 간격과 colorbar 여백은 추론 완료 후 수정했다. 그림과 보고서만 다시 생성했고 RGB·prediction·수치·실행 시간은 바꾸지 않았다. 실제 추론에 사용한 프로그램은 원본 출력 폴더의 `program.py`에 보존했다. 각 실행의 `results.json`에는 추론 프로그램과 최종 그림 생성 코드의 SHA-256을 따로 기록했다.

전체 10장 그림은 원본 출력의 `figures/`에 있다. 이 폴더의 `figures/crack-001.png`, `figures/print-001.png`는 결과 확인 후 각각 변화가 가장 큰 양·음 사례로 선택한 설명용 사본이다.
